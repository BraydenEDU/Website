# Site map and page briefs (Deliverable 1)

Every page ships in English at `/`, Spanish at `/es/` and Chinese at `/zh/`. The app (app.annuit.com: sign-in, billing) is out of scope.

| Page | URL | Purpose | Primary call to action |
|---|---|---|---|
| Home | `/` | Get a tax preparer who has never heard of Annuit to understand it within two minutes and book a demo | Book a demo (secondary: Get started) |
| Home: Features | `/#features` | Value strip plus Organize and Track features: show what Annuit does with real file names and a real checklist | Book a demo |
| Home: Solutions | `/#solutions` | Intake, Review, Follow-up: the whole product in three steps | Book a demo |
| Home: Resources | `/#resources` | Launch content: one customer story and the client document checklist | Read story / download (when ready) |
| Home: Pricing | `/#pricing` | Stripe pricing table and closing CTA | Get started |
| Pricing | `/pricing.html` | Full pricing table and the four questions buyers ask before paying | Get started |
| Security | `/security.html` | Answer the data-security objection; tie Annuit to the firm's IRS-required WISP | Book a demo |
| Book a demo / Contact | `/demo.html` | Capture demo requests and show the contact email | Request a demo |
| Privacy | `/privacy.html` | Legal requirement; text supplied by Annuit | None |
| Terms | `/terms.html` | Legal requirement; text supplied by Annuit | None |
| 404 | `/404.html` | Send lost visitors back to a CTA | Book a demo |

**Global navigation:** Features, Solutions, Security, Resources, Pricing, a language switch (EN / ES / 中文), Sign in (app.annuit.com), Book a demo, Get started (sign-up at www.annuit.com, then onboarding).

**Footer:** Product (Features, Solutions, Security, Pricing), Resources (Customer stories, Document checklist, Book a demo), Company (Contact, Privacy, Terms).

**Search engines:** `sitemap.xml` (with language alternates), `robots.txt`, a canonical URL and share tags on every page.
